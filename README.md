## 📊 Project Details

### 1. 🎬 Bollywood Celebrity Detector
- **Type:** Face Recognition / Computer Vision
- **Accuracy:** 85%+
- **Description:** Matches users to 100+ Bollywood celebrities using VGG-Face (4096-dim vectors) and cosine similarity
- **Tech:** DeepFace, VGG-Face, MTCNN, Streamlit

### 2. 🐱 Cat VS Dog Classifier
- **Type:** Binary Classification / Computer Vision
- **Accuracy:** 96.5%
- **Description:** CNN built from scratch with data augmentation and dropout (50%)
- **Tech:** TensorFlow, CNN, OpenCV, Streamlit

### 3. 🔢 Handwritten Digit Classifier (CNN)
- **Type:** Multi-Classification / Computer Vision
- **Accuracy:** 99.6%
- **Description:** CNN model for MNIST digit recognition with optimized architecture
- **Tech:** TensorFlow, CNN, MNIST, Streamlit

### 4. 🔢 Handwritten Digit Classifier (ANN)
- **Type:** Multi-Classification / Deep Learning
- **Accuracy:** 97.8%
- **Description:** ANN model for MNIST - shows CNN performs better for image tasks
- **Tech:** TensorFlow, ANN, MNIST, Streamlit

### 5. 📊 Customer Churn Predictor
- **Type:** Binary Classification / Business AI
- **Accuracy:** 85%+
- **Description:** ANN model predicting churn with risk analysis dashboard
- **Tech:** TensorFlow, ANN, Scikit-learn, Streamlit

### 6. 🎓 Graduate Admission Predictor
- **Type:** Regression / Education AI
- **Metric:** RMSE 0.048
- **Description:** ANN model predicting admission chances (0-100%) using 7 academic features
- **Tech:** TensorFlow, ANN, Regression, Streamlit

### 7. 👗 Fashion Recommender System
- **Type:** Similarity Search / Computer Vision
- **Accuracy:** 85% top-5
- **Description:** Transfer learning with ResNet50 processing 44,441 fashion images
- **Tech:** ResNet50, KNN, TensorFlow, Streamlit

### 8. 🎥 Movie Recommender System
- **Type:** Content-Based Filtering / NLP
- **Description:** TF-IDF and Cosine Similarity on 5,000+ movies with TMDB API integration
- **Tech:** Scikit-learn, TF-IDF, Cosine Similarity, Streamlit

### 9. 🏅 Olympics Analysis System
- **Type:** Data Visualization / Business Intelligence
- **Description:** Interactive dashboard exploring 120+ years of Olympic history with Plotly
- **Tech:** Plotly, Pandas, Streamlit
